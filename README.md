# KG Calculator RED — Cloudflare

Плоская версия проекта: все файлы находятся в корне, вложенных папок нет.

Начните с FIRST-STEPS-RU.md. Требования: SPEC-RU.md. Подробные команды запуска: LAUNCH-RU.md. Дополнения ниже имеют приоритет над старой схемой размещения.

Главное меню: Духи, Мой профиль, Помощь. Кого крепить — внутри Духов. Проверенные пороги и правила усиления пока отсутствуют. ИИ выключен по умолчанию; при включении выбирает утверждённые ответы по функциям бота, автоматически пробуя Groq и OpenRouter.

Node.js 24 LTS: npm ci, npm test, npm run check:deploy. Публикация: npm run deploy — сначала автоматически выполняет тесты. Секреты добавляются отдельно в Cloudflare.

В этой плоской версии нет GitHub Actions: GitHub требует для них вложенную папку .github/workflows. Проверки выполняются локально и автоматически перед командой публикации. Файл worker.mjs — точка входа. Секреты в GitHub не загружать.

Профили хранятся в Cloudflare Durable Objects. Прежние main.py, profiles.py и render.yaml не используются. Если старый бот работает на Render, остановите его до настройки webhook: при запуске он удаляет webhook нового бота. Старые профили автоматически не переносятся.
