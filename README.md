# KG Calculator RED

Русскоязычный Telegram-бот для Kingdom Guard. Версия 1.0: «Духи», «Мой профиль», «Помощь». «Кого крепить» вложено в «Духи». Калькуляторы недоступны и отсутствуют в меню.

Начните с [пошаговой инструкции](docs/LAUNCH-RU.md). Полные требования — [ТЗ](docs/SPEC-RU.md), состояние проверок — [отчёт](docs/STATUS-RU.md).

Игровые пороги и правила усиления намеренно не заполнены. Бот не предсказывает победу. ИИ распознаёт вопросы о функциях бота и выбирает утверждённые ответы; свободная генерация игровых рекомендаций не включена.

Репозиторий https://github.com/snoopy-3d/KG-Calculator-RED при подготовке возвращал 404 через подключение GitHub. Этот пакет — самостоятельный проект, а не проверенное обновление существующего кода. Перед загрузкой сравните содержимое репозитория. Секретов в пакете нет.

Технологии: Cloudflare Workers, отдельный Durable Object с SQLite-хранилищем для каждого игрока, Telegram webhook. Компьютер после запуска можно выключить.

## Структура

```text
.github/workflows/check.yml  проверки GitHub без секретов и без публикации
src/bot.mjs                  меню, профиль, расчёты, ИИ
src/data.mjs                 проверенные пороги (пока пусто)
src/worker.mjs               webhook, хранилище, защита
scripts/telegram-setup.*     безопасная настройка Telegram
test/bot.test.mjs            автоматические проверки
wrangler.toml               настройки Cloudflare
docs/                       ТЗ, запуск, статус
```

Локальная проверка: Node.js 24 LTS, `npm ci`, `npm test`, `npm run check:deploy`. Запуск: `npx wrangler login`, `npm run deploy`, добавление секретов, повторный deploy, настройка webhook. Полная последовательность с пояснениями — в инструкции.
