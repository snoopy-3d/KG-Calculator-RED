# Загрузка без вложенных папок

Все файлы этого комплекта загружаются прямо в корень GitHub. Папки src, scripts, docs, test и .github для него не нужны.

## Очистка старых файлов

1. Откройте репозиторий, Code → Download ZIP. Сохраните копию. Если старый бот уже работает и имеет профили, сохраните отдельно его базу: ZIP репозитория её не содержит. Старые профили в новую версию не переносятся автоматически.
2. В переключателе веток main создайте ветку cloudflare-flat-v1. Если она уже есть, выберите её. Все дальнейшие действия выполняйте в ней.
3. Удаляйте только проверенные старые файлы: main.py, profiles.py, config.py, requirements.txt, render.yaml, test_bot.py, env.example, download. Откройте каждый → меню … справа над содержимым → Delete file → Commit changes в текущую ветку. Если кнопки нет, проверьте, что открыт файл и выбрана ваша ветка.
4. README.md отдельно удалять не нужно: он заменится новым. Файл download — прежнее содержимое списка игнорирования, а не нужная часть нового бота.
5. Add file → Upload files. Выберите ВСЕ файлы из этого комплекта, включая .gitignore, но не саму папку UPLOAD-FILES. Сохраните Commit changes в ветку cloudflare-flat-v1. Ни одного токена здесь быть не должно.
6. Убедитесь, что package.json, worker.mjs и wrangler.toml видны сразу на главной странице ветки. Вложенной папки UPLOAD-FILES быть не должно.
7. Если ранее уже загружали предыдущий комплект из этого чата, удалите в этой ветке папки src, scripts, docs, test и .github, удаляя файлы внутри них по одному. При удалении последнего файла GitHub убирает пустую папку. Не удаляйте неизвестные файлы без проверки.
8. Compare & pull request → Create pull request. Просмотрите изменения. Затем Merge pull request → Confirm merge. Это ваши действия в GitHub; они не выполнены автоматически.

## Важные поправки к LAUNCH-RU.md

Этот комплект заменяет прежнюю структуру. Игнорируйте упоминания папок src/scripts/docs/test/.github и загрузки папок в разделе 4 старой подробной инструкции. Все файлы теперь в корне. Статус репозитория обновился: он доступен, исходные 9 файлов проверены.

GitHub Actions в плоском комплекте не настроены, поэтому зелёного задания «Проверки» в Actions ожидать не нужно. Вместо него выполните npm.cmd ci, npm.cmd test, npm.cmd run check:deploy в локальной папке. Команда npm.cmd run deploy сама повторяет тесты перед размещением.

Настройка Telegram: powershell -NoProfile -ExecutionPolicy Bypass -File .\telegram-setup.ps1

Далее выполняйте разделы 5–11 LAUNCH-RU.md: вход Cloudflare, первая публикация, секреты, необязательный ИИ, webhook и ручная проверка. Новый токен сначала получите после /revoke в BotFather. Никому не отправляйте его.
